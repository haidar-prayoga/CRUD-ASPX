# ASPX CRUD Project - Printing Management

Proyek ini adalah aplikasi web CRUD sederhana menggunakan ASP.NET Web Forms (ASPX) dengan bahasa pemrograman Visual Basic (VB.NET). Aplikasi ini digunakan untuk mengelola data terkait sistem pencetakan dokumen.

## 📂 Fitur Utama

- Tambah data
- Ubah data
- Hapus data
- Tampilkan daftar data

## 🛠 Teknologi yang Digunakan

- ASP.NET Web Forms (ASPX)
- Visual Basic (VB.NET)
- SQL Server (T-SQL)

## 🧱 Persiapan Database

Sebelum menjalankan proyek ini, kamu perlu membuat database terlebih dahulu.

### Langkah-langkah:

1. Buka SQL Server Management Studio (SSMS) atau tools database lainnya.
2. Buat database baru dengan nama `db_printing` (atau sesuai kebutuhan kamu).
3. Jalankan skrip SQL yang tersedia di file `db_printing.sql` untuk membuat tabel-tabel yang dibutuhkan.

   **Cara menjalankan skrip:**
   - Klik kanan pada database yang baru kamu buat > `New Query`
   - Copy dan paste isi dari file `db_printing.sql` ke dalam jendela query
   - Tekan tombol **Execute** atau `F5`

## 🚀 Cara Menjalankan Proyek

1. Buka Visual Studio
2. Pilih menu `File` > `Open` > `Website...`, lalu arahkan ke folder proyek ini
3. Sesuaikan `connectionString` di file `Web.config` agar sesuai dengan konfigurasi server dan database kamu
4. Jalankan proyek dengan menekan `F5`
